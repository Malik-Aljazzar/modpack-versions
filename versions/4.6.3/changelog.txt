## 4.6.3

Performance cleanup - KubeJS and unused libraries removed, Colorwheel added for shaders with Create.

- **Removed: KubeJS, KubeJS Create and Rhino.** The pack never used KubeJS on the client (only its example scripts), but its built-in local web server (`localhost:61423`) ran in a busy loop as long as the game was open: one CPU core at 100 % on high priority, plus roughly 50 MB/s of garbage for the Java garbage collector. Without it the game stutters less, most noticeably on laptops and CPUs with few cores
- **Removed unused libraries:** Collective, CreativeCore, Caelus API, Berezka API, Bad Packets, flib, MaFgLib, Prism, Temporal API, LDLib and Forge Config API Port. No mod in the pack depends on them any more; they only cost startup time and memory
- **Removed: Sinytra Connector** - it loads Fabric mods on NeoForge, and the pack no longer contains any Fabric-only mod
- **Removed: Not Enough Animations** together with its add-on EMF Compat: Not Enough Animations
- **Removed: Snow Under Trees.** Snow that is already lying under trees stays (it is normal vanilla snow); newly generated chunks no longer get snow under trees, and snow no longer piles up under trees while it snows
- **New: Colorwheel 1.3.1** - lets Iris shader packs work with Flywheel, the renderer Create uses for moving parts and contraptions (client only)
- Server: KubeJS, LootJS and the experimental Async mod are gone from the server as well; spawn protection and the idle Distant Horizons pre-generation are now handled by the server's own fix mod
- No world changes; no items, blocks or recipes are affected. The server restarts once for this update
